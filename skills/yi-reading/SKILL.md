# 易 · yi-reading

一次占問是**一段對話**，不是一次查詢。整件事的立足點是榮格的共時性：
卦不預告將來，它是把提問那一刻的心境翻譯成一個可以端詳的形狀。
人看見自己所處的位置，行動就從看見裏自己長出來。

## 立刻要知道的三件事

1. **不斷吉凶，不作預測。**「大吉」「凶」「會不會成」「什麼時候」——這些詞不出現在你的輸出裏。
   經文裏本來就有「吉」「凶」字樣，照引無妨，但**你自己不下這種判斷**，
   而是講它在說什麼樣的處境。
2. **不得把自己寫的話冒充注家原文。** 每一句聲稱是蘇軾的話，都必須能用
   `verify_quote.py` 驗過。第 36–64 卦沒有原文可引——就說沒有。
3. **不引五行生克、納甲、六親、應期。** 那是象數派的預測系統，
   它的目標函數與這裏相反。

## 一次占問的六步

### 第一步 · 把處境收成一個可占的問題

用戶通常帶著一團事情來。你的活是把它收斂成**一個可占的問題**。判據很簡單：

- 可占：問**位置與方向**——「我此刻在這件事裏處在什麼位置」「該往哪裏用力」
- 不可占：問**結果**——「我會不會升職」「他會不會回來」「幾月能成」

用戶給的若是預測型問題，**當場改寫成處境型，並明說你改了什麼、為什麼改**。
不要沉默地替換——被替換而不知情，是騙。

### 第二步 · 復述並等一句確認

把改寫後的問題**原樣復述**，等用戶說「就問這個」。這一步不可省。
按榮格的講法，提問時的心境與擲出的卦是同一刻的兩面；
這句確認是讓那個「一刻」成立的動作，不是禮儀。

### 第三步 · 起卦

```bash
python3 skills/yi-reading/scripts/reading.py
```

一次擲完六爻，但**把每一擲報給用戶看**（第幾擲、三枚是背是字、和數、老陽/少陰/少陽/老陰）。
用戶不需要逐爻觸發——過程可見即可，不必變成六次點擊。

用的是**金錢卦**：三枚硬幣，背為陽記 3、字為陰記 2；和 6 老陰、7 少陽、8 少陰、9 老陽；
自下而上擲六次。榮格為《易經》英譯本作序時當場起的那一卦，用的就是硬幣。

隨機源是 `secrets`。**不要**改成 `random`——可復現的偽隨機與共時性是互斥的。

### 第四步 · 發卦象圖

從 `assets/hexagrams/` 取圖，文件名即 `NN-卦名.png`：

```bash
lark-cli im +messages-send --as bot --chat-id <id> --file skills/yi-reading/assets/hexagrams/03-屯.png
```

有動爻就同時發本卦與之卦兩張。**動爻不在圖上**（靜態圖表達不了 2⁶ 種組合），
用文字說明：「初九、六四為動爻」。

### 第五步 · 說清為什麼讀這一句

`reading.py` 已按朱熹《易學啟蒙·考變占》選好了經文，並給出 `rule_text` 與 `why`。
**把這個理由講給用戶聽**——市面上的產品在這一步經常直接跳過或做錯。

| 動爻數 | 讀什麼 |
|---|---|
| 0 | 本卦卦辭（內卦為貞、外卦為悔） |
| 1 | 本卦該動爻的爻辭 |
| 2 | 本卦兩條動爻的爻辭，以上爻為主 |
| 3 | 本卦與之卦的卦辭；變爻組合在變卦圖前十位主本卦，後十位主之卦 |
| 4 | 之卦中兩條不變爻的爻辭，以下爻為主 |
| 5 | 之卦中那條唯一不變爻的爻辭 |
| 6 | 乾占用九、坤占用六；其餘卦讀之卦卦辭 |

注意「彖辭」在《啟蒙》裏指**卦下之辭（卦辭）**，不是《彖傳》。同名不同物。

### 第六步 · 解讀，三層

按這個次序，一層一層落到用戶的具體處境上。**通篇不超過三四百字**——
話多了就成了勸世文，那正是要避免的東西。

1. **情勢**（蘇軾一路）：何以至此，此刻這個局面是什麼形狀。
   蘇軾看的是**情勢**——事情怎麼走到這一步，各方的力在往哪裏使。
   這一層引《東坡易傳》原文（前 35 卦有；沒有的如實說沒有）。
2. **應對**（程頤一路 ＋ 大象傳）：處在這個位置上的人當如何。
   大象傳的「君子以……」是現成的行動語句，直接用。
   程頤看的是**規範**——什麼是此位當守的分寸。⚠️ 目前沒有可靠的《伊川易傳》電子本，
   凡按程頤讀法寫的話，必須標明「這是按程頤的讀法轉述，非原文」。
3. **收束**（榮格）：這一卦照見了你原本沒看見的哪一面。
   一兩句，不要展開講理論。落點是用戶的處境，不是榮格。

## 引注家原文之前，先驗

```bash
python3 skills/yi-reading/scripts/verify_quote.py --dongpo 3 "因世之“屯”，而務往以求功"
```

退出碼 0 才可以說「蘇軾說」。比對只忽略空白，標點繁簡一律不歸一化——
歸一化就等於允許改字，而引用的全部價值就在逐字可核。

`reading.py` 的輸出裏，`commentary[].available` 為 `false` 時，
**照直告訴用戶這一卦沒有蘇注可引**，然後只用經傳解。不要拿自己的話填空。

## 幾種要當場處理的情況

**「我剛才那卦不好，再起一卦」** —— 不重擲。告訴他：卦是那一刻的鏡子，
不滿意的是鏡子裏的東西，換面鏡子照不掉。如果他的處境或問題**真的變了**，
那是另一個問題，可以另起一卦——但要他先說清變的是什麼。

**「所以到底能不能成？」** —— 直說這套東西不回答這個，並把問題翻過來：
「如果它成，需要你此刻做成什麼；如果不成，最可能卡在哪一步。」

**用戶在情緒的急處** —— 先把人接住，別急著擲。有時候他要的只是把事說出來，
說完發現不用占了，那也是好結果。

**涉及醫療、法律、財務、人身安全的決定** —— 明確說這裏不提供那類判斷，
建議去找相應的人。卦可以照見心境，不能替代診斷。

## 腳本

| 腳本 | 用途 | 什麼時候跑 |
|---|---|---|
| `scripts/reading.py` | 起卦 ＋ 按考變占斷卦 ＋ 取經文與蘇注 | 每次占問 |
| `scripts/cast.py` | 只起卦 | 一般不單獨用 |
| `scripts/verify_quote.py` | 核對引文是否為原文逐字子串 | 每次引注家之前 |
| `scripts/build_table.py` | 推導 64 卦卦畫表並自校驗 | 構建期 |
| `scripts/fetch_texts.py` | 抓經文與《東坡易傳》 | 構建期 |
| `scripts/render_hexagrams.py` | 渲染 64 張卦象圖 | 構建期，改風格時 |

`reading.py --json` 給完整結構（含蘇注全文），`--values 9,8,8,6,7,8` 可重放一次占問。

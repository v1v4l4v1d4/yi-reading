# 依据

`reading.py` 里的断卦规则不是从二手讲义抄的。这一页记下原文出处与逐条核对过程，
以便日后有人怀疑某一支选错了句，可以直接回到原文吵。

## 考变占七条

出自朱熹《易学启蒙·考变占》。所用底本为维基文库《易学启蒙通释》（四库全书本）卷下
——胡方平的通释逐句引朱子原文并加注，注文正好交代了几处原文说不清的地方。

> 凡卦六爻皆不變，則占本卦彖辭，而以內卦為貞、外卦為悔。
> 一爻變，則以本卦變爻辭占。
> 二爻變，則以本卦二變爻辭占，仍以上爻為主。
> 三爻變，則占本卦及之卦之彖辭，即以本卦為貞、之卦為悔，前十卦主貞，後十卦主悔。
> 四爻變，則以之卦二不變爻占，仍以下爻為主。
> 五爻變，則以之卦不變爻占。
> 六爻變，則乾坤占二用，餘卦占之卦彖辭。

三处容易误读，记在这里：

**「彖辭」指卦下之辞，即卦辞，不是《彖传》。** 通释原注：「彖辞为卦下之辞」。
这两个东西同名不同物，混起来会让零爻变和三爻变两支全错。

**二爻变取上爻、四爻变取下爻，方向相反不是笔误。** 朱子的理由通释引了：
「凡变须就其变之极处看，所以以上爻为主；不变者是其常，只顺其先后，
所以以下爻为主——亦如阴阳老少之义。」

**「前十卦主贞、后十卦主悔」需要知道「第几卦」怎么数。** 见下节。

## 三爻变：前十／后十的次序是怎么定下来的

朱熹把六十四卦之变列为三十二图，每图以一对卦为首末。对某一本卦而言，
它的 63 个之卦按「所變之爻」排定次序：一爻变六卦、二爻变十五卦、三爻变二十卦、
四爻变十五卦、五爻变六卦、六爻变一卦。原文：

> 今以六十四卦之變列為三十二圖……變在第三十二卦以前者占本卦爻之辭，
> 变在第三十二卦以后者占变卦爻之辞。

通释的注给了两个可以验算的锚点：

> 如乾三爻變，自否至恒為前十卦，自益至泰為後十卦；
> 如坤三爻變，自泰至益為前十卦，自恒至否為後十卦。

**验算。** 假设次序就是「动爻位置集合的字典序」（自下而上编号 1..6），
C(6,3)=20 种依次为 (1,2,3), (1,2,4), …, (4,5,6)：

| | 干（111111）变出 | 坤（000000）变出 |
|---|---|---|
| 第 1 位 (1,2,3) | 000111 ＝ **否** ✓ | 111000 ＝ **泰** ✓ |
| 第 10 位 (1,5,6) | 011100 ＝ **恒** ✓ | 100011 ＝ **益** ✓ |
| 第 11 位 (2,3,4) | 100011 ＝ **益** ✓ | 011100 ＝ **恒** ✓ |
| 第 20 位 (4,5,6) | 111000 ＝ **泰** ✓ | 000111 ＝ **否** ✓ |

四个锚点、两个独立的本卦，全部吻合。所以这个排序不是猜的，
`reading.py` 的 `TRIPLES` 就按字典序写，`tests/test_yi.py::test_變卦圖次序的四個錨點`
把这四个点钉死——日后谁动了排序，测试会拦住。

顺带一提，这条总则与七条规则是自洽的：一、二爻变落在「第三十二卦以前」故读本卦，
四、五、六爻变落在其后故读之卦，三爻变恰好跨在分界上，于是一分为二。
自洽本身也是一重旁证。

## 起卦法

**金钱卦**（本项目默认）。三枚硬币同掷：背为阳记 3、字为阴记 2；
三枚之和 6 老阴、7 少阳、8 少阴、9 老阳；自下而上掷六次。
每爻四象概率：老阳 1/8、少阴 3/8、少阳 3/8、老阴 1/8，动爻概率 1/4。

选它的理由是原则性的，不是图快：**荣格为卫礼贤《易经》英译本作序时，
当场为这本书起卦所用的正是硬币法。** 这个项目整个立足于他那套共时性，
机制上与他同源比与朱熹同源更要紧。

**大衍筮法**（未实现，接口预留）。四象概率为老阳 3/16、少阴 7/16、少阳 5/16、老阴 1/16
——动爻总概率同样是 1/4，但偏心：阳极而变比阴极而变多三倍，
与「亢龍有悔」那一路义理相合。这个不对称在学界有争论，焦点是二三变要不要继续「挂一」。
真要实现时须在文档中并列两说。

## 四库本的切分与代价

**按卦画切，不按卦名切。** 每卦开头有 `{{SKchar|NNNN}}{{SK notes|震下坎上}}`，
由上下卦反查卦序，再断言全书恰好覆盖 1..64 且次序单调。
按名字对必然漏——四库本异体字极多，光一个「兌」就有 兌／兑／兊 三种写法，
「无咎」写作「元咎」。按卦画对不会错，因为卦画只有八个符号。

**代价是无标点。** 所以引它时取短句（四到十来个字），长段落用自己的话讲。
`{{SK notes|…}}` 是双行小注——在《周易本义》里它就是朱熹的注本身，必须留；
`{{SK anchor|…}}` 是扫描页的导航锚点，内容与正文重复，去掉；
`{{SKchar|N}}` 是字库外的字，留 `□` 占位并计数，**不猜补**。

**不做繁简转换，也不代加标点。** 两者都是改字，而引用的全部价值在于逐字可核。
带标点的《东坡易传》1–35 卦子页体例本身也不统一（引号有「」有“”，第 27 卦整页简体），
一律照录。

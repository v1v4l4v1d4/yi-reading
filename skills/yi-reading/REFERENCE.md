# 依據

`reading.py` 裏的斷卦規則不是從二手講義抄的。這一頁記下原文出處與逐條核對過程，
以便日後有人懷疑某一支選錯了句，可以直接回到原文吵。

## 考變占七條

出自朱熹《易學啟蒙·考變占》。所用底本為維基文庫《易學啟蒙通釋》（四庫全書本）卷下
——胡方平的通釋逐句引朱子原文並加注，注文正好交代了幾處原文說不清的地方。

> 凡卦六爻皆不變，則占本卦彖辭，而以內卦為貞、外卦為悔。
> 一爻變，則以本卦變爻辭占。
> 二爻變，則以本卦二變爻辭占，仍以上爻為主。
> 三爻變，則占本卦及之卦之彖辭，即以本卦為貞、之卦為悔，前十卦主貞，後十卦主悔。
> 四爻變，則以之卦二不變爻占，仍以下爻為主。
> 五爻變，則以之卦不變爻占。
> 六爻變，則乾坤占二用，餘卦占之卦彖辭。

三處容易誤讀，記在這裏：

**「彖辭」指卦下之辭，即卦辭，不是《彖傳》。** 通釋原注：「彖辭為卦下之辭」。
這兩個東西同名不同物，混起來會讓零爻變和三爻變兩支全錯。

**二爻變取上爻、四爻變取下爻，方向相反不是筆誤。** 朱子的理由通釋引了：
「凡變須就其變之極處看，所以以上爻為主；不變者是其常，只順其先後，
所以以下爻為主——亦如陰陽老少之義。」

**「前十卦主貞、後十卦主悔」需要知道「第幾卦」怎麼數。** 見下節。

## 三爻變：前十／後十的次序是怎麼定下來的

朱熹把六十四卦之變列為三十二圖，每圖以一對卦為首末。對某一本卦而言，
它的 63 個之卦按「所變之爻」排定次序：一爻變六卦、二爻變十五卦、三爻變二十卦、
四爻變十五卦、五爻變六卦、六爻變一卦。原文：

> 今以六十四卦之變列為三十二圖……變在第三十二卦以前者占本卦爻之辭，
> 變在第三十二卦以後者占變卦爻之辭。

通釋的注給了兩個可以驗算的錨點：

> 如乾三爻變，自否至恒為前十卦，自益至泰為後十卦；
> 如坤三爻變，自泰至益為前十卦，自恒至否為後十卦。

**驗算。** 假設次序就是「動爻位置集合的字典序」（自下而上編號 1..6），
C(6,3)=20 種依次為 (1,2,3), (1,2,4), …, (4,5,6)：

| | 乾（111111）變出 | 坤（000000）變出 |
|---|---|---|
| 第 1 位 (1,2,3) | 000111 ＝ **否** ✓ | 111000 ＝ **泰** ✓ |
| 第 10 位 (1,5,6) | 011100 ＝ **恒** ✓ | 100011 ＝ **益** ✓ |
| 第 11 位 (2,3,4) | 100011 ＝ **益** ✓ | 011100 ＝ **恒** ✓ |
| 第 20 位 (4,5,6) | 111000 ＝ **泰** ✓ | 000111 ＝ **否** ✓ |

四個錨點、兩個獨立的本卦，全部吻合。所以這個排序不是猜的，
`reading.py` 的 `TRIPLES` 就按字典序寫，`tests/test_yi.py::test_變卦圖次序的四個錨點`
把這四個點釘死——日後誰動了排序，測試會攔住。

順帶一提，這條總則與七條規則是自洽的：一、二爻變落在「第三十二卦以前」故讀本卦，
四、五、六爻變落在其後故讀之卦，三爻變恰好跨在分界上，於是一分為二。
自洽本身也是一重旁證。

## 起卦法

**金錢卦**（本項目默認）。三枚硬幣同擲：背為陽記 3、字為陰記 2；
三枚之和 6 老陰、7 少陽、8 少陰、9 老陽；自下而上擲六次。
每爻四象概率：老陽 1/8、少陰 3/8、少陽 3/8、老陰 1/8，動爻概率 1/4。

選它的理由是原則性的，不是圖快：**榮格為衛禮賢《易經》英譯本作序時，
當場為這本書起卦所用的正是硬幣法。** 這個項目整個立足於他那套共時性，
機制上與他同源比與朱熹同源更要緊。

**大衍筮法**（未實現，接口預留）。四象概率為老陽 3/16、少陰 7/16、少陽 5/16、老陰 1/16
——動爻總概率同樣是 1/4，但偏心：陽極而變比陰極而變多三倍，
與「亢龍有悔」那一路義理相合。這個不對稱在學界有爭論，焦點是二三變要不要繼續「掛一」。
真要實現時須在文檔中並列兩說。

## 四庫本的切分與代價

**按卦畫切，不按卦名切。** 每卦開頭有 `{{SKchar|NNNN}}{{SK notes|震下坎上}}`，
由上下卦反查卦序，再斷言全書恰好覆蓋 1..64 且次序單調。
按名字對必然漏——四庫本異體字極多，光一個「兌」就有 兌／兑／兊 三種寫法，
「无咎」寫作「元咎」。按卦畫對不會錯，因為卦畫只有八個符號。

**代價是無標點。** 所以引它時取短句（四到十來個字），長段落用自己的話講。
`{{SK notes|…}}` 是雙行小注——在《周易本義》裏它就是朱熹的注本身，必須留；
`{{SK anchor|…}}` 是掃描頁的導航錨點，內容與正文重複，去掉；
`{{SKchar|N}}` 是字庫外的字，留 `□` 佔位並計數，**不猜補**。

**不做繁簡轉換，也不代加標點。** 兩者都是改字，而引用的全部價值在於逐字可核。
帶標點的《東坡易傳》1–35 卦子頁體例本身也不統一（引號有「」有“”，第 27 卦整頁簡體），
一律照錄。
